# BUG-001: Sorting by price (low to high) does not sort for problem_user

**Severity:** Major | **Priority:** High | **Found by:** automated test

**Test:** tests/test_known_bugs.py::test_price_sort_for_each_user[chromium-problem_user]

## Steps to reproduce
1. Go to https://www.saucedemo.com
2. Log in as problem_user / secret_sauce
3. Choose "Price (low to high)" in the sort menu

## Expected
Products listed from lowest to highest price.

## Actual
Order is unchanged: 29.99, 9.99, 15.99, 49.99, 7.99, 15.99

## Impact
Shoppers cannot find the cheapest items. Works correctly for standard_user,
so the defect is user-specific, which suggests a state or configuration issue.

## Evidence
Screenshot from a manual reproduction, plus the failing run from the automated test.
