# BUG-002: Checkout accepts a blank last name for error_user

**Severity:** Major | **Priority:** Medium | **Found by:** exploratory testing, then automated

**Test:** tests/test_known_bugs.py::test_checkout_requires_last_name_for_error_user[chromium]

## Steps to reproduce
1. Go to https://www.saucedemo.com
2. Log in as error_user / secret_sauce
3. Click "Add to cart" on Sauce Labs Backpack
4. Open the cart and click "Checkout"
5. Enter First Name "David", leave Last Name blank, enter Postal Code "34994"
6. Click "Continue"

## Expected
The error "Error: Last Name is required" is shown and you stay on the
Checkout: Your Information form.

## Actual
No error is shown and you go on to the Checkout: Overview page.

## Impact
Orders can be placed without a customer last name. standard_user gets the
error, so the defect is user-specific.
